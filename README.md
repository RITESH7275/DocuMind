# DocuMind

AI-Powered Document Intelligence Platform.

## Overview

DocuMind allows users to upload private documents and ask
questions about their content using Retrieval-Augmented Generation (RAG).

## Planned Stack

- FastAPI
- PostgreSQL
- pgvector

- React / Next.js
- Docker
- AWS
